# FMCG Financial Ratio Analysis Dashboard (Power BI)

## Overview

This project analyzes the financial performance of the top 5 FMCG companies in India using Microsoft Power BI. The dashboard compares profitability, return ratios, leverage, valuation, and dividend metrics across multiple financial years.

## Tools & Technologies

* Microsoft Power BI
* DAX
* Power Query
* Python (data transformation pipeline)
* Excel (data source)

## Companies Analyzed

* Britannia Industries
* Hindustan Unilever (HUL)
* ITC Limited
* Nestlé India
* Varun Beverages

## Dashboard Features

* Executive KPI overview
* Sales and profit trend analysis
* Profitability vs. shareholder returns
* Valuation vs. growth comparison
* Leverage and dividend analysis
* Interactive company and year slicers
